# TAU GPS Bridge

Проект моста для подключения и интеграции GNSS-модуля **TAU2202**
(а также модулей серии TAU1201/TAU1308 и совместимых) к устройствам
на базе **Android** через микроконтроллер **ESP32-C3**.

> ⚠️ **Дисклеймер:** Код проекта написан в режиме **vibe coding** —
> то есть в тесной связке с ИИ-ассистентом, без формального
> проектирования и с минимумом тестов. Это **pet-проект для
> собственных нужд**, а не продакшн-решение.  
> Используйте на свой страх и риск. Возможны баги, недочёты
> в архитектуре и неочевидные edge-кейсы.

---

## 📌 О проекте

Основная цель — подружить двухчастотный GNSS-приёмник TAU2202
с операционной системой Android:

1. Принимать сырой NMEA-поток и бинарные пакеты от модуля через
   промежуточный контроллер **ESP32-C3**.
2. Передавать точные координаты (включая RTK Fixed/Float и 3D Fix)
   в системный сервис фиктивных местоположений Android
   (**Mock Location**) для навигационных приложений
   (Яндекс.Навигатор, 2ГИС, OsmAnd и др.).
3. Отображать детальную телеметрию в реальном времени: качество сигнала
   (C/N0 по диапазонам L1/L5/B1/B2a/E1), количество спутников по
   созвездиям (GPS, BeiDou, GLONASS, Galileo), статус активной антенны,
   точность (DOP) и калибровку инерциальной навигации (INS/DR).

## ⚠️ Ограничения и предупреждения

- **Не для продакшена.** Проект создан для личного использования.
  Если планируете использовать его в коммерческих целях —
  проведите аудит кода, добавьте тесты, покройте граничные случаи.
- **Минимум тестов.** Автотесты отсутствуют. Проверка — только
  ручная, на реальном железе.
- **Платформенные нюансы.** Mock Location детектируется некоторыми
  навигаторами (Яндекс.Навигатор, 2ГИС могут показать предупреждение
  о фиктивной геолокации). Обойти это без root невозможно.
- **Android 14+** ужесточает правила работы mock location и
  foreground service. На новых прошивках возможны сюрпризы.
- **ESP32-C3 не тестировался на всех ревизиях.** На разных платах
  встроенный LED может висеть на разных пинах.

## 🔌 Аппаратная часть и прошивка ESP32-C3

Связь между модулем TAU2202 и Android осуществляется через плату
ESP32-C3 в режиме прозрачного UART-USB моста (Raw Bridge).

- **Прошивка для ESP32-C3:** `esp32-c3/sketch_sep19a/sketch_sep19a.ino`
- **Подключение контактов (ESP32-C3 ↔ TAU2202):**
  - `PIN 20 (RX)` ← TX GNSS-модуля
  - `PIN 21 (TX)` → RX GNSS-модуля
  - `GND` ↔ `GND`
  - `VCC (3.3V)` ↔ `VCC` ⚠️ **только 3.3 В, не 5 В**
- **Настройки в Arduino IDE:**
  - Board: *ESP32C3 Dev Module*
  - USB CDC On Boot: *Enabled* — обязательно, иначе Serial пойдёт
    в UART0 и конфликтует с пинами GNSS
  - Скорость порта: *115200 бод*
  - CPU Frequency: *160 MHz* (либо 80 MHz для меньших помех)

> ℹ️ **Проверен только USB (USB OTG / USB-CDC).**  
> Bluetooth SPP (RFCOMM) добавлен в код, но **полностью
> непроверен** — может не работать, может падать, может
> вести себя непредсказуемо. Считайте его экспериментальной
> заготовкой, а не готовой функцией.

## 📱 Возможности Android-приложения

### Монитор GNSS и созвездий
- Статус фикса (RTK Fixed, RTK Float, 3D Fix, DGPS, 2D Fix).
- Раздельная статистика по группировкам: GPS, BeiDou, GLONASS,
  Galileo с уровнем сигнала (дБГц).
- Точность (DOP: PDOP, HDOP, VDOP) на выделенной строке.
- Состояние антенны (активная OK, пассивная/обрыв, КЗ),
  поддержка диапазонов L1+L5.
- Координаты, скорость, высота (MSL), азимут/курс и UTC время.
- Статус и рекомендации калибровки инерциальной системы (INS/DR).

### Терминал логов и отправка команд
- Просмотр NMEA-сообщений, бинарных ответов и HEX-пакетов
  в реальном времени.
- Предустановленные команды управления модулем: горячий/тёплый/
  холодный старт, сохранение конфигурации, переключение
  одно-/двухчастотного режима, сброс к заводским настройкам.
- Кнопки управления: «Старт/Пауза», «Копировать», «Стереть».

### Настройки и управление подключением
- Единый блок выбора типа подключения (USB / Bluetooth SPP)
  и сканирования устройств.
- Автоматический опрос и отображение версии ПО/железа модуля
  в строке выбранного устройства.
- Авто-подключение к ранее использованному устройству
  (по серийному номеру, `VID:PID` или MAC-адресу).
- Выбор скорости порта (Baud Rate) и окончаний строк (CRLF, LF, CR).
- Управление Mock Location (трансляция координат в систему Android).

## 🛠️ Сборка проекта

**Требования:**
- Android Studio / IntelliJ IDEA: Ladybug / Meerkat (AGP 8.x+)
- JDK: 11+ (совместимо с JDK 17/21)
- Min SDK: 24 (Android 7.0)
- Target SDK: 36 (Android 15+)
- Jetpack Compose & Material 3

**Шаги:**
1. Склонировать репозиторий
2. Открыть проект в Android Studio.
3. Прошить ESP32-C3 скетчем из `esp32-c3/`.
4. Подключить ESP32-C3 к Android-устройству через USB-OTG.
5. В приложении: **Настройки → Разрешить фиктивное местоположение**
   (активируется через «Параметры разработчика»).
6. **Настройки → Mock Location → Вкл**.
7. Открыть Яндекс.Навигатор / 2ГИС — координаты придут с модуля.

## 🐛 Известные проблемы

- **Уведомление foreground service** отображается постоянно,
  пока активна трансляция. Это требование Android,
  убрать невозможно.
- **Mock Location детектируется** Яндекс.Навигатором и 2ГИС.
  Приложение может показать предупреждение.
- **Первый запуск** может потребовать ручного выбора устройства
  в списке — авто-подключение работает только к ранее использованным.
- **Bluetooth SPP не проверен.** Функциональность добавлена в код,
  но не тестировалась на реальном железе.
