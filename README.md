# TAU GPS Bridge

Проект моста для подключения и интеграции GNSS-модуля **TAU2202** (а также модулей серии TAU1201/TAU1308 и совместимых) к устройствам на базе **Android** через микроконтроллер **ESP32-C3**.

---

## 📌 О проекте

Основная цель проекта — подружить двухчастотный GNSS-приёмник TAU2202 с операционной системой Android:
1. Принимать сырой NMEA-поток и бинарные пакеты от модуля через промежуточный контроллер **ESP32-C3**.
2. Передавать точные координаты (включая RTK Fixed/Float и 3D Fix) в системный сервис фиктивных местоположений Android (**Mock Location**) для навигационных приложений (Яндекс.Навигатор, 2ГИС, OsmAnd и др.).
3. Отображать детальную телеметрию в реальном времени: качество сигнала (C/N0 по диапазонам L1/L5/B1/B2a/E1), количество спутников по созвездиям (GPS, BeiDou, GLONASS, Galileo), статус активной антенны, точность (DOP) и калибровку инерциальной навигации (INS/DR).

---

## 🔌 Аппаратная часть и прошивка ESP32-C3

Связь между модулем TAU2202 и Android осуществляется через плату ESP32-C3 в режиме прозрачного UART-USB моста (Raw Bridge).

- **Прошивка для ESP32-C3:** файл расположен в `esp32-c3/sketch_sep19a.ino`.
- **Подключение контактов (ESP32-C3 <-> TAU2202):**
  - `PIN 20 (RX)` <- TX GNSS-модуля
  - `PIN 21 (TX)` -> RX GNSS-модуля
  - `GND` <-> `GND`
  - `VCC (3.3V / 5V)` <-> `VCC`
- **Настройки в Arduino IDE:**
  - Board: *ESP32C3 Dev Module*
  - USB CDC On Boot: *Enabled*
  - Скорость порта: *115200 бод*

> ℹ️ *На текущий момент протестирована и поддерживается работа через USB (USB OTG / USB-CDC). Архитектура приложения также включает поддержку Bluetooth SPP (RFCOMM).*

## 📱 Возможности Android-приложения

- **Монитор GNSS и созвездий:**
  - Статус фикса (RTK Fixed, RTK Float, 3D Fix, DGPS, 2D Fix).
  - Раздельная статистика по группировкам: GPS, BeiDou, GLONASS, Galileo с уровнем сигнала (дБГц).
  - Точность (DOP: PDOP, HDOP, VDOP) на выделенной строке.
  - Состояние антенны (Активная OK, пассивная/обрыв, КЗ), поддержка диапазонов L1+L5.
  - Координаты, скорость, высота (MSL), азимут/курс и UTC время.
  - Статус и рекомендации калибровки инерциальной системы (INS/DR).
- **Терминал логов и отправка команд:**
  - Просмотр NMEA сообщений, бинарных ответов и HEX пакетов в реальном времени.
  - Предустановленные команды управления модулем (сброс INS, горячий/тёплый/холодный старт, настройка частоты и NMEA).
  - Кнопки управления: «Старт/Пауза», «Копировать» и «Стереть».
- **Настройки и управление подключением:**
  - Единый блок выбора типа подключения (USB / Bluetooth SPP) и сканирования устройств.
  - Автоматический опрос и отображение версии ПО/железа модуля в строке выбранного устройства.
  - Выбор скорости порта (Baud Rate) и окончаний строк (CRLF, LF, CR).
  - Управление Mock Location (трансляция координат в систему).
